## PR #6で反映した修正

- 主ボタンを **「開始メッセージをコピー」** に統一。
- コピー後はAIのチャットへ貼り付けて送信する手順を表示。自動送信・自動ログインはしない。
- 共有ボタンはSite URLだけを共有。共有取消で意図しないコピーをしない。
- 「今日は変なのがいい」「笑いたい」「怖くないSF」など、明示した少数の表現を既存タグへ対応。
- `怖くないSF` は `SF` と `怖くない` の両方を要求。
- 対応する少数の「〜は嫌い / なし / 苦手」表現を除外条件へ変換。
- 気分未指定時は異なる体験の入口を少数提示。全件Catalogの順序は維持。
- GM開始時に「周りを見る」「今の状況は？」「中断」の最小案内を一度だけ追加。
- 内部規約は通常プレイで読み上げない一方、取得失敗や技術的な質問には事実どおり答える。
- Seed投稿を仮題・`world`・`initial_state`中心へ簡略化。
- 音声ログなし、作品名不明でもプレイ報告できるように変更。
- LPフッターからSeed投稿とプレイ報告へ直接移動できるように変更。
- 56 Story objectの内容ハッシュを固定し、今回の変更で作品本文が変わっていないことを検査。
- 公開版をGETだけでcheckoutと照合する `scripts/check-public-beta.mjs` を追加。

## Sites公開後の必須確認

対象版をSitesへ公開したら、完全なcheckoutで次を実行する。

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm test
npm run test:types
npm run check:sync
npm run verify
node scripts/check-public-beta.mjs --url https://yohaku-trpg.unjuno.chatgpt.site
```

`check-public-beta.mjs` は次を確認する。

1. 公開Catalogがcheckoutの全作品と一致する
2. 全Story本文と共通GMガイドが一致する
3. 代表的な気分検索がcheckoutと一致する
4. compat Catalogがbounded subsetの契約を守る
5. SSRされた入口に新しいCTAとコミュニティリンクが存在する

取得不能や版の不一致をPASSにしない。

続けて実ブラウザで確認する。

- スマートフォン / デスクトップ
- コピー許可時
- コピー拒否時の手動コピー
- AIへ貼り付けて送信
- 共有操作の取消
- 戻る操作
- 文字拡大
- キーボード操作
- 対応WebMCPブラウザではtool登録と実呼出
- 未対応ブラウザではHTTP/コピー経路

## 初見試遊

### 仮説

初見の人が制作側の口頭補助なしで、「開始 → 一つの行動 → 状況確認 → 中断」まで到達できる。

### 最小確認

同意を得た5人程度を目安に、音声とテキストの両方を含める。これは統計的保証ではなく、公開導線の重大な欠陥を見つけるための確認。

1人最大15分程度。嫌になれば即中断。全文ログの提出は不要。

最低限記録するもの:

- 実施日
- 作品名（分かる場合）
- テキスト / 音声
- 開始できたか
- 最初の自発的行動が出たか
- 「今の状況は？」等で具体的な整理が返ったか
- 「中断」で止まれたか
- また遊びたいか（任意）
- 問題があれば短い実例

短時間で満足して終えた場合と、操作や進行に困って離脱した場合は分ける。

### FAIL条件

次のいずれかが再現した場合、その導線は修正対象。

- コピー・貼り付け・取得が原因で開始できない
- 内部規約や「原本」「世界を固める」等を通常プレイで読み上げる
- 未知の世界情報をプレイヤーへ逆質問する
- 既出事実を進行都合で変更する
- 明示的に避けたジャンルを推薦する
- 中断要求を無視して物語を進める

修正後は同じ確認項目を再実行する。

## 一回の問題報告から直す場所

| 症状 | 最初に見る場所 |
| --- | --- |
| 作品が見つからない / 0件 | 選前メタデータ、気分マッピング、除外、取得失敗との区別 |
| 貼り付け前に止まる | CTA、コピー結果、AIへ移動する説明 |
| 「何と書いてある？」を逆質問 | 共通GMガイド、直前描写。隠し真相を追加して対処しない |
| 「設定を固定する」と読み上げる | 内部指示と通常発話の境界 |
| 初動が生まれない | `world` / `initial_state` の人物・物・出来事。攻略法は足さない |
| 面白くない | 実例を聞いてSeedを改稿。コードPASSを根拠に否定しない |

1. PR #6相当の版がSites本番へ反映されている
